# Портфолио Никиты Кутылова

Статичный сайт (HTML, CSS, JS без сборки) в папке `site/`. Его можно выложить на любой хостинг, который умеет отдавать файлы.

## Что внутри
- `site/index.html` — хаб: обо мне, работы, услуги, процесс, контакты.
- `site/works/taganay-expedition` — лендинг «Тропа Таганая» (редакторский стиль, походы из Златоуста).
- `site/works/belogorye` — лендинг «Белогорье» в исходном виде из курса (горнолыжный курорт, видео и фото Pexels).
- `site/works/meridian` — лендинг «Меридиан» в исходном виде из курса (клуб походов по Швейцарии, фото Unsplash).
- `site/works/assistant` — демо ИИ-помощника заявок (стиль NEUROCAREER). Работает на правилах в браузере, без ИИ и без отправки данных.
- `site/credits.html` — авторы и лицензии всех фотографий.

Все четыре работы демонстрационные: компании вымышленные, цены, цифры и отзывы внутри образцовые. В «Тропе Таганая» фотографии с Wikimedia Commons (CC BY, CC BY-SA, общественное достояние), в «Белогорье» и «Меридиан» стоковые материалы Pexels и Unsplash.

## Команды
```
npm run serve     # открыть сайт на http://localhost:8801
npm test          # проверки: ссылки, чужой контент, лицензии, логика помощника
npm run photos    # заново скачать фото и обновить credits.json
npm run credits   # пересобрать site/credits.html
node tools/shots.mjs     # скриншоты и проверка ошибок на ПК и телефоне (нужен Chrome и Playwright из соседнего проекта)
node tools/interact.mjs  # проверка кликов, модалок, форм, переходов (там же)
```

## Что проверено
13 тестов (`npm test`) и 29 проверок интерактива в настоящем Chrome: модалки маршрутов с галереей, листание, меню на телефоне, формы, переходы с хаба и обратно, диалог помощника.

## Что не проверено
- Сайт не выложен в интернет: нужен хостинг и домен.
- Заявки в формах никуда не уходят (демо). Для настоящего клиента форму подключают к Telegram.
- Тексты о Таганае (высоты, расстояния) взяты из открытых источников и даны «около»; перед использованием в боевом проекте сверяйте с официальными данными нацпарка.
- Шрифты загружаются с Google Fonts, без интернета заменяются системными.

## Лицензии
Код сайта: ваш. Фотографии: см. `site/credits.html`; их можно использовать с указанием автора и лицензии (для CC BY-SA производные фото тоже под CC BY-SA).
Вёрстка трёх лендингов основана на учебных шаблонах из курса; тексты, структура и фотографии заменены.
